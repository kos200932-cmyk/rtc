# SHM-KB25: parts of the joint DMRD-KB25 + RI70-KV95, flange layout (user, 2026-10-22). J1 (under the ОПУ) and J6.
# Coordinates: the frame of DMRD-KB25 (x=0 - motor end of the input shaft), mm. Level 2: interfaces only.
# Link interface: the previous link (J1: the base) on the REDUCER side of the flange, bore D110H7 on the reducer ring
# D110h7; 12 x M4 DIN912 on D120 through the flange (heads on the motor side) into M4 of the link (D120: thread 2.5 mm
# from the link bore). Flange D136. Flange -> reducer: 12 x M4 DIN912 from the output side through the reducer
# 12 x D4.5 (D102) into M4 of the flange. The 4-M3 of the reducer ring (D102, 45 deg) are not used.
# Rotor cup, clamp flange and stator clamp - as in SHM-60 (same reducer and motor):
#   torque: shaft -> 6xM3 -> clamp flange -> 3xM3 -> cup -> rotor (RI70 peak 2.68 N*m); cables D20.
#   The clamp flange (D38, x 59.5..62.5) turns with the INPUT shaft: the next link needs a recess >= D44 x 4.
