Генерация руки RTC-7 v2 в SolidWorks 2017 (макрос BuildFromSpec v27, ветка joints-structure)
==========================================================================================

Что получится: сборка robot\RTC-7-v2-J1-J7.SLDASM в нулевой позе. В неё входят:
  ОПУ RU178G;
  7 шарниров: J1 SHM-KB25, J2 SHM-1000 (80E), J3 SHM-KB50, J4 SHM-KB45, J5 SHM-KB32,
    J6 SHM-KB25, J7 SHM-60;
  6 звеньев из links-v2 (цилиндры посадки, рёбер пока нет).
Звенья закреплены на выходных валах шарниров, так что степени свободы руки сохранены.

1. Подготовка
   1.1. Распакуйте архив в НОВУЮ папку без пробелов и кириллицы в пути, например C:\rtc_v2\.
        Не распаковывайте поверх старой папки с уже построенными моделями: при REBUILD no макрос
        не перестраивает существующие файлы и возьмёт старые (например, LINK-3 с рёбрами).
   1.2. В SolidWorks закройте все документы (Окно - Закрыть все).
        Не открывайте одновременно старую руку (robot\RTC-7-J1-J7). У звеньев v1 и v2 одинаковые
        имена файлов (LINK-1 ... LINK-6, LINK-n-01_Weldment), а SolidWorks не держит в памяти
        два документа с одним именем из разных папок.
   1.3. Шаблоны по умолчанию для детали и сборки (Параметры - Шаблоны по умолчанию).
        В шаблоне детали не должно быть материала: масса задаётся плотностью из описания.

2. Подключение макроса (один раз)
   2.1. Инструменты - Макрос - Создать..., сохраните, например, C:\rtc_v2\BuildFromSpec.swp.
   2.2. В редакторе VBA: File - Import File... - macros\BuildFromSpec.bas.
   2.3. Tools - References: должны быть включены SldWorks 2017 Type Library и
        SOLIDWORKS 2017 Constant type library (в новом макросе они обычно уже есть).
   Если макрос уже подключён, но версия старше v27, удалите старый модуль и импортируйте заново.

3. Построение всей руки (рекомендуется, один запуск)
   3.1. Инструменты - Макрос - Выполнить - BuildFromSpec.swp (процедура main).
   3.2. В окне выбора файла укажите robot\RTC-7-v2-J1-J7.txt.
   3.3. Макрос по очереди построит недостающие модели. Каждая сохраняется рядом со своим
        описанием и закрывается:
          components\ISKRA\RU178G\           ОПУ
          components\DMRD\KB25|KB32|KB45|KB50|80E\   редукторы
          joints\SHM-KB25|SHM-1000|SHM-KB50|SHM-KB45|SHM-KB32|SHM-60\   шарниры
                                               (двигатели T-motor импортируются из STEP)
          links-v2\LINK-1 ... LINK-6\          звенья
        Затем он соберёт robot\RTC-7-v2-J1-J7.SLDASM. Эта сборка останется открытой.
   3.4. В конце появится окно Done / Finished with warnings / Stopped.

4. Построение по частям (если хотите проверить звено до всей руки)
   Каждый файл запускается отдельно через main, так же как в п. 3:
     links-v2\LINK-3\LINK-3.txt      одно звено (деталь + сборка LINK-3), детали в системе координат робота;
     joints\SHM-KB45\SHM-KB45.txt    один шарнир;
     robot\RTC-7-v2-J1-J7.txt        рука. Уже построенные модели она возьмёт готовыми.

5. Проверка результата
   5.1. В дереве должны быть OPU, J1...J7, L1...L6 (14 компонентов верхнего уровня).
   5.2. Массы звеньев (Анализ - Массовые характеристики, по деталям звена) - для сверки:
          LINK-1 4,64 кг   LINK-2 2,66 кг   LINK-3 13,15 кг
          LINK-4 6,84 кг   LINK-5 5,70 кг   LINK-6 1,41 кг   (AlMg, 2700 кг/м3)
   5.3. Подвижность: перетаскивание звена поворачивает шарнир. Без касаний:
          J2 -95...+95 (рабочий предел ±93), J4 -170...+170,
          J1, J3, J5, J6, J7 - полный оборот.
        Сопряжений-передач нет: входные валы и роторы вращаются независимо от выходных.
   5.4. Проверка пересечений (Инструменты - Проверка пересечений) в нулевой позе:
        пересечений быть не должно (задние крышки шарниров пока не моделируются).

6. Перестроение после изменений в описаниях
   - Перестроить одну модель: закройте сборку, удалите её файлы (.SLDPRT / .SLDASM) в папке
     описания, например links-v2\LINK-3\, и запустите руку снова. Недостающее построится, остальное
     возьмётся готовым.
   - Перестроить всё: в robot\RTC-7-v2-J1-J7.txt поставьте REBUILD yes. Это заметно дольше.

7. Если что-то пошло не так
   - Пришлите текст итогового окна макроса целиком (Finished with warnings / Stopped / Runtime error)
     и скриншот дерева.
   - Ошибки при построении: в начале макроса поставьте FAST_MODE = False (экран перерисовывается,
     видно, на какой операции остановилось) и повторите.
   - Чтобы окна моделей не закрывались после сохранения: CLOSE_DOCS = False.
   - "Документ с таким именем уже открыт": закройте всё (п. 1.2), в том числе старую руку v1.
