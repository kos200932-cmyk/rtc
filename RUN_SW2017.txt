Запуск генерации в SolidWorks 2017 (архив rtc, ветка joints-structure, макрос BuildFromSpec v27)

1. Распакуйте архив в папку без пробелов и кириллицы в пути, например C:\rtc\.
2. SolidWorks 2017: Инструменты - Макрос - Создать... (или откройте существующий .swp),
   в редакторе VBA: File - Import File... -> macros\BuildFromSpec.bas.
   Нужные ссылки (Tools - References): SldWorks 2017 Type Library, SOLIDWORKS 2017 Constant type library
   (обычно включены в новом макросе).
3. Запуск: процедура main (F5). Макрос спросит файл описания (*.txt) и построит детали/сборку
   рядом с ним. Перед повторным запуском закройте ранее построенные документы с теми же именами.
4. Шаблоны: макрос берёт шаблоны детали/сборки по умолчанию (Параметры - Шаблоны по умолчанию),
   иначе ищет в папке шаблонов SW 2017 или спросит *.prtdot / *.asmdot.
   В шаблоне детали не должно быть назначенного материала (масса задаётся плотностью).

Окна документов (v27): каждая деталь и промежуточная сборка (редуктор, шарнир внутри руки) закрывается
  сразу после сохранения, модели для сборок открываются без окон. Открытой остаётся только сборка,
  которую вы запускали (или последняя деталь, если в описании только детали). Отключить: в начале
  макроса CLOSE_DOCS = False. FAST_MODE = True - SolidWorks не перерисовывает экран во время построения
  (быстрее); если построение пойдёт с ошибками, поставьте FAST_MODE = False и сообщите.

Что запускать (каждый файл - отдельный запуск main):
  Анимация руки (новое, макрос v26): robot\RTC-7-anim.txt - вставляет модели руки без сопряжений
    и проигрывает демо-программу (596 кадров, 15 кадров/с), каждый кадр сохраняется в
    robot\RTC-7-anim-frames\f0000.jpg ... Сначала должна быть построена рука (RTC-7-J1-J7.txt).
    В файле: IMAGES none - только проиграть на экране; RANGE 0 100 - часть кадров; ZOOM 0.8 - масштаб.
    Видео из кадров: ffmpeg -framerate 15 -i f%04d.jpg -pix_fmt yuv420p RTC-7-anim.mp4
    Перед запуском разверните окно SolidWorks - картинки сохраняются в размере окна.
  Вся рука: robot\RTC-7-J1-J7.txt (ОПУ, шарниры J1..J7, звенья 1-6, сопряжения по степеням свободы).
  Сборка руки (новое, макрос v24): robot\RTC-7-J1-J3.txt - ОПУ, шарниры J1..J3, звенья 1-2 в нулевом
    положении; недостающие модели строятся сами (REBUILD yes в файле - перестроить всё).
  Звенья (новое, призматические детали):
    links\LINK-1\LINK-1.txt            звено 1: сварная деталь + переходник J1, сборка LINK-1
                                        (детали в мировой системе робота, нулевое положение)
  Шарниры целиком (редуктор + двигатель + детали шарнира, сборка шарнира):
    joints\SHM-60\SHM-60.txt
    joints\SHM-150\SHM-150.txt
    joints\SHM-500\SHM-500.txt
    joints\SHM-1000\SHM-1000.txt
  Отдельные компоненты:
    components\DMRD\KB25|KB32|KB45|KB50|80E\DMRD-*.txt редукторы (3 детали + сборка); KB50 - новый (J3 новой компоновки)
    components\ISKRA\RU178G\RU178G-UU-CC0-P5.txt      ОПУ (2 кольца + сборка)
    Двигатели T-motor - STEP + карточки (components\T-motor\...), импортируются при сборке шарнира.

Если что-то не построится - пришлите текст итогового окна макроса (Finished with warnings / Stopped)
и, по возможности, скриншот дерева.

Проверка без SolidWorks (Python 3 + pip install cadquery-ocp matplotlib numpy):
  python tools\link_build.py links\LINK-1\LINK-1.txt --joints J1,J2 --step --png link1.png
  python tools\spec_preview.py <описание детали>.txt --png out.png
Компоновка, кинематика, моменты: robot\ (RTC-7-layout.txt, RTC-7-kinematics.md, RTC-7-statics.md).
Движение: robot\RTC-7-demo.txt - программа (MOVEJ / MOVEL / WAIT / GRIP / RELEASE / LABEL);
  python tools\robot_anim.py --check 6 --html robot\anim\RTC-7-viewer.html --sw robot\RTC-7-anim.txt
  robot\anim\RTC-7-viewer-offline.html - то же без интернета (двойной щелчок, Chrome / Edge / Firefox),
  robot\anim\RTC-7-viewer.html - просмотрщик в браузере (ползунки осей, моменты, проигрывание),
  robot\anim\RTC-7-demo.mp4 - видео, robot\anim\RTC-7-demo.csv - углы и TCP по кадрам.
