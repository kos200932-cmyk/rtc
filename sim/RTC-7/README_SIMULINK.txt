RTC-7 в MATLAB / Simulink R2024a (Simscape Multibody)
=====================================================

Нужно: MATLAB, Simulink, Simscape, Simscape Multibody (R2024a; должно работать и с R2022b+).

1. Распакуйте папку RTC-7 целиком (RTC-7.urdf рядом с папкой meshes).
2. В MATLAB перейдите в эту папку и выполните:

     rtc7_build

   Скрипт:
   - импортирует RTC-7.urdf (smimport) в модель RTC7.slx: ОПУ и корпус J1 закреплены на мире,
     звенья 1-7, шарниры J1..J7 (Revolute Joint), инструмент с грузом 8 кг;
   - задаёт каждому шарниру движение от входа (углы демо-программы robot/RTC-7-demo.txt,
     40 с) и вычисляемый момент, выводит момент в рабочую область (tau_J1..tau_J7);
   - запускает расчёт и строит графики моментов; пунктиром - тот же расчёт в Python
     (RTC-7-demo-torques-ref.csv), числа должны совпасть с точностью до долей процента.
   Результат в рабочей области: rtc7.t, rtc7.q (рад), rtc7.tau (Н·м). Анимация - окно
   Mechanics Explorer, открывается само при запуске.

   Варианты:
     rtc7_build('run', false)    % только построить модель
     rtc7_build('speed', 2)      % та же траектория в 2 раза быстрее
     rtc7_build('program', 'n0') % программа на номинальных скоростях шарниров n0 (RTC-7-n0-traj.csv)
     rtc7_build('drive', false)  % только импорт: шарниры без приводов (для своей схемы управления)
   Просто посмотреть модель: smimport('RTC-7.urdf')
   С Robotics System Toolbox: robot = importrobot('RTC-7.urdf'); show(robot)

3. Графики движений и моментов по каждому шарниру:

     rtc7_plots                      % после rtc7_build (или сам запустит моделирование)

   Для каждого шарнира J1..J7 - окно из 4 графиков по времени программы: заданные угол,
   скорость, ускорение и момент на выходе редуктора (Simscape; серым - составляющая от веса,
   пунктиром - эталон Python; линии - номинальный и пусковой моменты редуктора).
   Сводно: моменты всех шарниров в % пускового; пик (% пускового) и RMS (% номинала).
   Таблица пиков - в окне команд и в rtc7_peaks (рабочая область), файлы - в папке plots
   (J1_motion_torque.png ... J7, all_joints_torque.png, peaks.png, rtc7_peaks.csv).
   Варианты:
     rtc7_plots('speed', 2)          % программа вдвое быстрее (моделирование заново)
     rtc7_plots('program', 'n0')     % программа на скоростях n0, графики в plots_n0\
     rtc7_plots('rerun', true)       % перезапустить моделирование
     rtc7_plots('joints', [1 2])     % окна только для J1, J2
     rtc7_plots('source', 'python')  % те же графики по расчёту Python - без Simscape
     rtc7_plots('save', false)       % не сохранять картинки

4. Если скрипт сообщит, что не смог подключить порты шарнира (имена параметров в разных версиях
   немного отличаются), он всё равно сохранит модель с готовыми блоками q_Jn / S2PS_Jn /
   PS2S_Jn / tau_Jn - соедините вручную: S2PS_Jn -> порт q шарнира, порт t -> PS2S_Jn,
   и запустите модель кнопкой Run.

Что в модели
- Нулевая поза = рука вытянута вверх, как в сборке SolidWorks; углы и направления осей те же,
  что в просмотрщике и анимации. Системы координат звеньев параллельны мировой в нулевой позе
  и стоят на осях шарниров. Единицы: м, кг, кг·м².
- Массы: звенья по объёму построенных деталей; шарниры - массы по каталогу (корпус+двигатель
  на предыдущем звене, выходной вал на следующем), инерция по профилям деталей; интерфейс
  смены инструмента 4 кг; груз 8 кг - блок с центром масс в 100 мм от фланца. Масса DMRD-80E
  в каталоге не указана, оценена 17,3 кг. Таблица масс: RTC-7-bodies.csv.
- НЕ учтено: инерция роторов двигателей через редуктор, трение и КПД редукторов, кабели.
  Их можно добавить в шарнирах (Internal Mechanics) или отдельными блоками.
- Пределы осей в URDF: J2 ±94°, J4 ±171°, остальные ±180°; effort = номинальный момент
  редуктора; скорость 3,14 рад/с - условно.

Пересоздать файлы из описаний проекта (Python, папка rtc):
  python tools/urdf_export.py --payload 8       -> sim/RTC-7/ (URDF, STL, траектория)
  python tools/program_retime.py               -> robot/RTC-7-demo-n0.txt, RTC-7-n0-traj.csv (скорости n0 из
                                                  robot/RTC-7-joint-requirements.txt)
  python tools/joint_compare.py                -> robot/RTC-7-joint-compare.md (нагрузки шарниров против требований)
  python tools/robot_dynamics.py [--speed 2]    -> robot/RTC-7-dynamics.md / .png, эталон моментов
