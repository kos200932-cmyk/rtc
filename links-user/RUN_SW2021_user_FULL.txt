Генерация в SolidWorks 2021: ПОЛНЫЙ МАНИПУЛЯТОР RTC-7 J1..J7 с подсборкой КИСТИ (2026-11-09) - макрос BuildFromSpec v36

Файл для запуска: links-user\RTC-7-user-J1-J7.txt
Состав: пластина переходная + ОПУ RU178G + J1 SHM-KB25 + Юла + звено 1 LINK-1U + J2 SHM-1000 (80E + AK80-9)
  + звено 2 LINK-2B + J3 SHM-KB50F + звено 3 LINK-3U + J4 SHM-KB45 + звено 4 LINK-4U
  + КИСТЬ (подсборка links-user\WRIST\RTC-7-wrist-J5-J7.txt) = J5 SHM-KB32 + звено 5 LINK-5U + J6 SHM-KB25
    + звено 6 LINK-6 + J7 SHM-KB17 (KB17 + RI70) + СЗУ (захват, TCP = торец СЗУ, 150 мм от фланца J7).
  Верхний уровень 12 компонентов, в кисти 6. Масса ~129 кг.

Архив чистый: готовых моделей SolidWorks в нём нет, всё строится из текстовых описаний в SW 2021 (модели SW 2021
не откроются в SW 2017 - для 2017 строить отдельно, links-user\RUN_SW2017_user_FULL.txt).

1. Распакуйте архив в папку без пробелов и кириллицы в пути, например C:\rtc_2021\ (структура папок сохраняется:
   components, joints, links-user, links-v2, macros).
2. SolidWorks 2021: Инструменты -> Макрос -> Новый (или откройте свой макрос) -> в редакторе VBA удалите старый модуль
   BuildFromSpec и импортируйте macros\BuildFromSpec.bas (v36). Запуск - процедура main.
   Нужны ссылки (Tools -> References): SldWorks 2021 Type Library, SOLIDWORKS 2021 Constant type library
   (обычно уже включены в новом макросе).
3. ПЕРЕЗАПУСТИТЕ SolidWorks перед запуском (в памяти не должно быть скрытых моделей прошлых запусков).
4. main -> выбрать links-user\RTC-7-user-J1-J7.txt. Первый запуск строит ВСЁ (редукторы DMRD, двигатели T-motor
   из STEP, шарниры, звенья, кисть, руку) - это долго (десятки минут), окно SolidWorks в это время не трогать.
   Порядок сам: компоненты -> шарниры -> звенья -> кисть RTC-7-wrist-J5-J7.SLDASM (строится, сохраняется,
   закрывается) -> рука RTC-7-user-J1-J7.SLDASM (остаётся открытой).
   v36: во всех эскизах деталей проставляются размеры - каждая точка эскиза получает горизонтальный и вертикальный
   размер от начала координат эскиза (это координаты из текстовых описаний), эскизы полностью определены (чёрные).
   Размеры есть только у деталей, построенных этим запуском: распаковывайте в новую папку (или REBUILD yes).
5. Ожидаемый итог (сообщение в конце, две строки сборок):
     arm assembly RTC-7-wrist-J5-J7: 6 component(s), lock mates: 2 of 2, revolute joints (REV): 3 of 3
     arm assembly RTC-7-user-J1-J7: 12 component(s), lock mates: 5 of 5, revolute joints (REV): 4 of 4
     sketch dimensions (v36): fully defined N of N sketch(es) - если меньше N, часть эскизов осталась недоопределённой
     (синие), пришлите это сообщение; строка "FullyDefineSketch error" - метод API не принял аргументы
6. Проверка: потяните звено 2 - рука от J3 поворачивается вокруг оси J2; звено 3 - вокруг J3; звено 4 - вокруг J4
   вместе с кистью; звено 5 - вокруг J5, звено 6 - вокруг J6, СЗУ - вокруг J7; Юлу / звено 1 - вокруг J1.
   Если звенья кисти в руке не поворачиваются: ПКМ по RTC-7-wrist-J5-J7 в дереве -> Свойства компонента ->
   Решить как: Гибкий (макрос ставит это сам; сообщите, если не встало). Кисть можно открыть и проверить отдельно:
   links-user\WRIST\RTC-7-wrist-J5-J7.SLDASM.
7. Если сборка рассыпалась (красные сопряжения в редукторе, детали с "(-)"): перезапустите SolidWorks, откройте
   components\DMRD\<тип>\DMRD-<тип>.SLDASM; если в нём ошибки - main -> components\DMRD\<тип>\DMRD-<тип>.txt,
   снова перезапуск и шаг 4 (уже построенное берётся готовым).

СТАТИЧЕСКАЯ СБОРКА (плоская, без подсборки кисти, все компоненты зафиксированы в нулевой позе):
  links-user\RTC-7-user-J1-J7-fixed.txt - запускать после полной сборки (модели берутся готовыми); для масс,
  геометрии, проверки пересечений.
