Генерация в SolidWorks 2017: ПОЛНЫЙ МАНИПУЛЯТОР пользователя J1..J7 (2026-10-24) - ОДИН ЗАПУСК, макрос BuildFromSpec v30

Файл: links-user\RTC-7-user-J1-J7.txt
Состав (16 компонентов): пластина переходная (Д16Т) + ОПУ RU178G + J1 SHM-KB25 + Юла + звено 1 LINK-1U + J2 SHM-1000 (80E + AK80-9)
  + звено 2 LINK-2B (короб 30ХГСА: плита 24, стенки 6, полка 10) + J3 SHM-KB50F (фланец D236) + звено 3 + J4 SHM-KB45 + звено 4
  + J5 SHM-KB32 + звено 5 + J6 SHM-KB25 + звено 6 + J7 SHM-KB17 (KB17 + RI70). Масса ~125 кг.

1. Распакуйте архив в папку без пробелов и кириллицы в пути (например C:\rtc_3\).
2. В редакторе VBA удалите старый модуль и импортируйте macros\BuildFromSpec.bas (v30). Запуск - процедура main.
3. ПЕРЕЗАПУСТИТЕ SolidWorks (не только "Закрыть все": в памяти остаются скрытые модели прошлых запусков).
   Если сборка уже рассыпалась (красные Заблокировать1 ротора в SHM-KB50F / SHM-KB17, детали редуктора с "(-)"):
   после перезапуска откройте components\DMRD\KB50\DMRD-KB50.SLDASM и components\DMRD\KB17\DMRD-KB17.SLDASM -
   если детали в них "(-)" или сопряжения красные, перестройте редуктор: main -> components\DMRD\KB50\DMRD-KB50.txt
   (и KB17\DMRD-KB17.txt), затем снова перезапустите SolidWorks.
4. main -> выбрать links-user\RTC-7-user-J1-J7.txt. Всё строится за один запуск:
   - звено 2 (LINK-2B), J3 (SHM-KB50F) и J7 (SHM-KB17) перестраиваются всегда (слово rebuild в строках COMP);
     редукторы внутри шарниров при этом берутся готовыми (v30) - их перестройка ломала сопряжения;
   - остальные модели строятся, если их ещё нет, иначе берутся готовыми;
   - чтобы перестроить ВСЁ заново: в файле REBUILD no -> REBUILD yes (долго).
5. Ожидаемый итог: arm assembly RTC-7-user-J1-J7: 16 component(s), lock mates: 14 of 14.
6. Проверка: J1..J7 поворачиваются перетаскиванием; предпросмотр - links-user\RTC-7-user-J1-J7-preview.png.

Если макрос остановится - пришлите текст итогового окна (Finished with warnings / Stopped).
