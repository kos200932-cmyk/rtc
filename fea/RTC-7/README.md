# RTC-7: исходные данные для расчёта прочности звеньев в Ansys Workbench 2024 R1

Сгенерировано `python tools/fea_export.py` из тех же описаний, что модель SolidWorks, Simscape и анимация.

## Состав

| Файл | Что это |
|---|---|
| `geometry/<звено>.step` | деталь в глобальной СК руки (нулевая поза, мм), зоны контакта интерфейсов выделены в отдельные грани |
| `cards/<звено>.md` | вариант «а»: описание детали — материал, СК, закрепление, нагрузка, случаи, проверка реакции, подшипник редуктора |
| `pictures/<звено>.png` | грани закрепления (синие) и нагрузки (оранжевые) |
| `rtc7_fea.json` | все данные для скриптов (правила выбора граней, нагрузки, ожидаемые реакции) |
| `ansys/rtc7_wb.py` | вариант «б»: скрипт Workbench — проект со всеми звеньями, материал, геометрия, запуск скрипта Mechanical |
| `ansys/rtc7_mech.py` | скрипт Mechanical — грани, закрепление, удалённая точка, силы/моменты/ускорения по шагам, сетка, результаты, расчёт |
| `ccx/summary.md` | предварительный расчёт здесь же (CalculiX) по тем же данным — ориентир до Ansys |

## Как запустить (вариант «б»)

1. Распакуйте папку `RTC-7` целиком (например `C:\rtc\fea\RTC-7`).
2. Workbench 2024 R1: File → Scripting → Run Script File… → `ansys\rtc7_wb.py`.
   Создаются системы Static Structural LINK-1 … LINK-6, LINK-1A, в каждой материал АМг6 и геометрия; по очереди открывается Mechanical, скрипт строит постановку и решает (в начале `rtc7_wb.py`: `ONLY = ["LINK-3"]` — только одно звено, `SOLVE = False` — без решения).
3. Результаты: `results_<звено>.csv` (σэкв max, допускаемое, запас, реакция: расчёт / ожидаемая) и `log_<звено>.txt` рядом с `rtc7_fea.json`; проект `RTC7_links.wbpj`.
4. Если что-то не создалось автоматически (имена вызовов API немного отличаются между версиями) — скрипт пишет предупреждение; Mechanical-часть можно запустить вручную: Automation → Scripting → `rtc7_mech.py` (в начале указать `CONFIG`). Пришлите текст ошибки — поправлю, как с макросом SolidWorks.

Вручную (вариант «а») — по карточкам `cards/*.md`, там же порядок действий.

## Постановка

- Материал AMg6: E 69.6 ГПа, ν 0.3, ρ 2640 кг/м³, σ0,2 155 МПа, σв 315 МПа. АМг6М листы 0,6-10,5 мм, ГОСТ 21631 (каталог ВИАМ): sigma_v >= 315, sigma_0.2 >= 155 МПа, E 69,6 ГПа, 2640 кг/м3; nu 0.30 и коэффициент прочности шва 0.9 - ПРИНЯТЫ.
- Требуемый запас по σ0,2: 1.5 в рабочих случаях S и D, 1 в предельном C; у сварных швов допускаемое ×0.9 (принято).
- Звено — одно тело (болты и швы не моделируются): грани закрепления жёстко закреплены, грани нагрузки жёстко связаны с удалённой точкой в центре интерфейса; на неё — сила и момент от корпуса следующего шарнира (= всё, что дальше по руке, плюс вес и инерция этого корпуса).
- Вес и ускорение самой детали — полем ускорений (Acceleration). Собственное вращение детали (центробежные силы) учтено только через ускорение центра масс — вклад мал.
- Груз 8 кг (центр масс в 100 мм от фланца) + интерфейс смены инструмента 4 кг; массы и инерции — модель руки `sim/RTC-7/RTC-7.urdf` (масса DMRD-80E оценочная).

Случаи:

- **S** — статика: поза руки с наибольшим моментом в закреплении звена (поиск по J2…J7 в пределах ходов).
- **D** — демо-программа с ускорениями: момент наибольший при выходе на максимальный вылет.
- **C** — упор инструмента (столкновение / аварийная ситуация): в позе S инструмент упёрся, приводы давят до пикового момента редуктора в первом же шарнире; направление силы — худшее для звена. Вместо «торможения пиковым моментом» как жёсткого тела: для кистевых осей оно даёт нереальные замедления (сотни–тысячи рад/с²) и абсурдные нагрузки.

## Попутно: выходные подшипники редукторов

Реакция в закреплении звена — это нагрузка на выходной вал шарнира, на котором звено стоит. Сравнение опрокидывающего момента с каталожным M_tilt:

| Звено | Шарнир | Редуктор | S, % M_tilt | D, % M_tilt | C, % M_tilt |
|---|---|---|---|---|---|
| LINK-1A | J1 | DMRD-KB32 (M_tilt 336) | — | 0 Н·м (0 %) | 0 Н·м (0 %) |
| LINK-2 | J2 | DMRD-80E (M_tilt 2156) | 228 Н·м (11 %) | 3 Н·м (0 %) | 703 Н·м (33 %) |
| LINK-3 | J3 | DMRD-KB45 (M_tilt 740) | 915 Н·м (124 %) | 1037 Н·м (140 %) | 3573 Н·м (483 %) |
| LINK-4 | J4 | DMRD-KB45 (M_tilt 740) | 311 Н·м (42 %) | 21 Н·м (3 %) | 1345 Н·м (182 %) |
| LINK-5 | J5 | DMRD-KB32 (M_tilt 336) | 274 Н·м (81 %) | 321 Н·м (96 %) | 2041 Н·м (607 %) |
| LINK-6 | J6 | DMRD-KB32 (M_tilt 336) | 32 Н·м (9 %) | 11 Н·м (3 %) | 650 Н·м (194 %) |

В рабочих случаях выход J3 (KB45) перегружен по опрокидывающему моменту, J5 (KB32) — на пределе: это вопрос выбора редукторов / разгрузки плеча, а не прочности звеньев. Случай C превышает M_tilt всех редукторов — его на практике ограничивает контроль моментов (обнаружение столкновения).
