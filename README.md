# rtc — скрипты для SolidWorks 2017

Макросы для автоматической генерации 3D-моделей с деревом построения по 2D-эскизам (чертежам).

## Как это устроено

```
скан / картинка чертежа  ──►  текстовое описание геометрии  ──►  VBA-макрос  ──►  .SLDPRT с деревом построения
```

VBA сам по себе не умеет распознавать изображения, поэтому шаг «картинка → описание» делается отдельно
(сейчас — вручную или с помощью Claude по присланному изображению), а макрос строит модель
по описанию: эскиз на нужной плоскости, затем элементы (вращение, вытяжка, вырезы).

## Макросы

| Макрос | Что делает |
|---|---|
| `macros/RevolveFromProfile.bas` | Тело вращения: эскиз «Profile» на плоскости «Спереди» (замкнутая ломаная + осевая линия) → элемент «Вращение» на 360° |

Восстановление детали по трём видам — следующий этап.

## Установка макроса

1. SolidWorks → **Инструменты → Макрос → Новый**, сохранить, например, `RevolveFromProfile.swp`.
2. В редакторе VBA: **File → Import File…** → выбрать `macros/RevolveFromProfile.bas`.
   Удалить пустой модуль, созданный по умолчанию (если он есть).
3. Проверить, что в **Tools → References** отмечены *SldWorks 2017 Type Library* и
   *SOLIDWORKS 2017 Constant type library* (в новом макросе они отмечены по умолчанию).
4. Запуск: **Инструменты → Макрос → Выполнить**, указать полный путь к файлу профиля.

Готовая деталь сохраняется рядом с файлом профиля под именем из строки `NAME`.

## Формат файла профиля (тело вращения)

```
# комментарий
NAME Вал_1          имя детали
P 0 0               точка профиля: X вдоль оси, Y — радиус, мм
P 0 15
...
```

- Точки обходят замкнутый контур по порядку; последняя соединяется с первой автоматически.
- Ось вращения — ось X модели. Радиусы `Y ≥ 0`, контур не должен самопересекаться.
- Фаски задаются точками (см. `examples/shaft.txt`), внутренние расточки — частью того же контура.
- Десятичный разделитель — точка или запятая.
