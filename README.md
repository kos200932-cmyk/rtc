# rtc — скрипты для SolidWorks 2017

Макросы для автоматической генерации 3D-моделей с деревом построения по 2D-чертежам.

## Как это устроено

```
скан / картинка чертежа  ──►  текстовое описание (spec)  ──►  VBA-макрос  ──►  .SLDPRT / .SLDASM с деревом построения
```

VBA не умеет распознавать изображения, поэтому шаг «картинка → описание» делается отдельно
(сейчас — вручную или с помощью Claude по присланному изображению), а макрос строит модели по описанию.

## Структура репозитория

```
components/            компонентная база: одна папка на типоразмер
  DMRD/KB25, KB32, KB45, 80E         редукторы (описание .txt + чертёж-источник)
  T-motor/RI70-KV95, RI80-V2-KV75,   бескорпусные двигатели и привод AK80-9
          RI115-PH-KV40, AK80-9-V3-KV100
joints/                шарниры манипулятора: состав, присоединения, проектируемые детали
  SHM-60, SHM-150, SHM-500, SHM-1000
  STATUS.md            отчёт проверки шарниров (генерируется)
macros/                VBA-макросы SolidWorks 2017
tools/joint_check.py   проверка шарниров: ссылки на порты, моменты, что ещё не заполнено
tools/spec_preview.py  проверка и картинка-разрез описания детали/сборки без SolidWorks
tools/step_inspect.py  разбор STEP тела вращения: ось, тела, соосные цилиндры, торцы, отверстия
                       (нужен pip install cadquery-ocp)
examples/              простые примеры формата
```

Файлы SolidWorks (`.SLDPRT/.SLDASM/.SLDDRW`) в репозиторий не кладутся — они генерируются макросами
из описаний (см. `.gitignore`). STEP производителей кладутся как есть, рядом с карточкой компонента.

## Шарниры

| Шарнир | Редуктор | Двигатель | Как ставится двигатель |
|---|---|---|---|
| ШМ-60 (`SHM-60`) | DMRD-KB25 | RI70 KV95 | ротор — через переходный стакан на входном валу Ø38h7; свой корпус статора |
| ШМ-150 (`SHM-150`) | DMRD-KB32 | RI80 V2.0 KV75 | ротор — через переходный стакан на входном валу Ø45h7; свой корпус статора |
| ШМ-500 (`SHM-500`) | DMRD-KB45 | RI115-PH KV40 | ротор — через переходный стакан на входном валу Ø65h7; свой корпус статора |
| ШМ-1000 (`SHM-1000`) | DMRD-80E | AK80-9 V3.0 KV100 | переходная плита + муфта (у привода свой корпус) |

Бескорпусные двигатели RI — это только статор и ротор, без корпуса и подшипников, поэтому для них
проектируются переходный стакан ротора (садится на входной вал редуктора и крепится к его торцу)
и корпус статора. AK80-9 — готовый привод с корпусом, к редуктору он
присоединяется через переходную плиту и муфту.

Проверка: `python tools/joint_check.py --out joints/STATUS.md`.

### Карточка компонента

```
COMPONENT <имя>
TYPE reducer | frameless_motor | actuator | sensor
DATA ключ=значение ...         каталожные данные; '?' — ещё не известно
STEP <файл.step>               для покупных моделей
PORT <имя> <x> <dir> ключ=значение ...
```

`PORT` — место присоединения: `x` — плоскость стыка по оси, `dir` — нормаль наружу (±1), дальше параметры:
`role` (input / output / fixed / stator_mount / rotor_mount), `pilot` / `shaft` / `od` / `id` — посадочный
диаметр, `bolts=6xM3` или `holes=12xD5.5`, `pcd`, `ang` — угол первого отверстия. У деталей, которые строит
макрос (редукторы DMRD), строки `PORT` стоят внутри своего `PART`. Макрос `BuildFromSpec` строки
`COMPONENT/TYPE/DATA/PORT/STEP` пока пропускает.

### Описание шарнира

```
JOINT <имя>
DATA T_nom=<Н·м>
USE    <роль> <компонент> <файл карточки>      роли: reducer, motor, sensor
DESIGN <деталь>                                проектируемая деталь шарнира
JOIN   <роль|деталь>.<порт>  <роль|деталь>.<порт>
OUT    base|output  <роль>.<порт>               интерфейсы шарнира для компоновки руки
END
```

## Макросы

| Макрос | Что делает |
|---|---|
| `macros/BuildFromSpec.bas` | Строит детали (тела вращения + круговые массивы отверстий) и, если задано, сборку из них |

Дерево каждой детали:

```
Спереди ─► Эскиз «Profile» (контур + осевая) ─► «Body» (вращение 360°)
Plane_X… (смещение от «Справа») ─► «HolesN_Sketch» ─► «HolesN» (вырез)
«HolesN_Sketch» ─► «ThreadN_M4» (вырез под резьбу) + косметическая резьба на каждом отверстии
«AXIS» — ось вращения (пересечение «Спереди» и «Сверху», совпадает с X)
«PORT_<имя>» — плоскость интерфейса + свойство детали PORT_<имя> = "x=… dir=… fit=… …"
```

В сборке:

- деталь с `MOTION fixed` (по умолчанию, у редукторов — корпус) привязана тремя сопряжениями
  «Совпадение» своих плоскостей к плоскостям сборки;
- деталь с `MOTION rotate` (входной и выходной валы) привязана к первой неподвижной детали двумя
  сопряжениями: `Rot_<деталь>_Axis` — ось на ось корпуса, `Rot_<деталь>_Axial` — плоскость «Справа»
  на плоскость «Справа». Остаётся одна свобода — вращение вокруг оси, вал можно крутить мышью;
- строки `DATA` (каталожные данные) записываются в свойства сборки (Файл → Свойства).

Интерфейсы для следующих сборок (шарнир, рука): ось `AXIS`, плоскость `PORT_<имя>` и, для угла
по крепежу, плоскости «Спереди»/«Сверху» детали (угол отверстий отсчитывается от +Z к +Y).

## Установка и запуск

1. SolidWorks → **Инструменты → Макрос → Новый**, сохранить, например, `BuildFromSpec.swp`.
2. В редакторе VBA: **File → Import File…** → `macros/BuildFromSpec.bas`.
   Удалить пустой модуль, созданный по умолчанию.
3. **Tools → References**: должны быть отмечены *SldWorks 2017 Type Library* и
   *SOLIDWORKS 2017 Constant type library*.
4. В **Параметры → Шаблоны по умолчанию** должны быть заданы шаблоны детали и сборки.
5. **Инструменты → Макрос → Выполнить** и выбрать файл описания (`.txt`) в окне открытия файла.

Детали и сборка сохраняются в папку файла описания. Перед повторным запуском закройте
открытые документы с теми же именами, иначе сохранение не пройдёт.

## Формат описания

```
# комментарий (также ';', можно в конце строки)
ASSEMBLY <имя сборки>          необязательно; без неё строятся только детали

PART <имя детали>
P <x> <y>                      точка замкнутого профиля: X вдоль оси, Y — радиус, мм
...
MOTION fixed | rotate          в сборке: неподвижна / вращается вокруг X относительно первой неподвижной
FLATS <x0> <x1> <размер> [n] [угол]   фрезерованные грани: всё снаружи правильного n-угольника (по умолч. 4 —
                               квадрат) «под ключ» <размер> срезается на длине x0..x1; угол — нормаль первой грани
KEYWAY <x> <dir> <длина> <ширина> <дно> <угол>   шпоночный паз: прямоугольник от оси до <дно> (расстояние от
                               оси до дна паза), шириной <ширина>, в направлении <угол>, на длину от плоскости x
MASS <кг>                      масса детали: макрос задаёт плотность = масса / объём (центр масс и
                               инерция — по геометрии); в шаблоне детали не должно быть материала
HOLES <x> <dir> <n> <pcd> <d> <depth> <angle>
THREAD <x> <dir> <n> <pcd> <size> <depth> <angle> [<drillDepth>]
PORT <имя> <x> <dir> [ключ=значение ...]   интерфейс: плоскость PORT_<имя> + свойство детали
END

COMPONENT / TYPE / STEP / FRAME   служебные строки карточки компонента, макрос их пропускает
                               (FRAME — ось и начало координат карточки в координатах STEP)
DATA ключ=значение ...         свойства сборки
```

Перед запуском в SolidWorks описание можно проверить: `python tools/spec_preview.py <файл.txt> --png out.png --ends ends.png`
— пересечения деталей, отверстия, вышедшие за стенку, картинка разреза.

`HOLES` — круговой массив отверстий:

| Поле | Смысл |
|---|---|
| `x` | положение торца по оси, мм (плоскость эскиза) |
| `dir` | `1` — сверлить в сторону +X, `-1` — в сторону −X |
| `n` | количество отверстий |
| `pcd` | диаметр окружности центров, мм |
| `d` | диаметр отверстия, мм (резьбу задавать диаметром под резьбу: M3 → 2.5, M4 → 3.3, M5 → 4.2) |
| `depth` | глубина, мм; `0` — насквозь |
| `angle` | угол первого отверстия, градусы: 0 — по оси +Z, 90 — по +Y (вверх) |

`THREAD` — круговой массив резьбовых отверстий: вырез сверлом под резьбу + косметическая резьба
на каждом отверстии (на чертеже даёт обозначение резьбы). Поля те же, что у `HOLES`, но вместо
диаметра — размер резьбы (`M1.6`…`M20`, сверло подставляется само), `depth` — глубина резьбы,
`drillDepth` — глубина сверления (по умолчанию глубина резьбы + 0.5·d).
«Мастер отверстий» не используется: в SW 2017 через API он строил неверную геометрию.

- Последняя точка профиля соединяется с первой автоматически. Радиусы `Y ≥ 0`, контур без самопересечений.
- Фаски задаются точками, расточки — частью того же контура.
- Десятичный разделитель — точка или запятая. Имена — латиницей.
