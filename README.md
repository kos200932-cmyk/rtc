# rtc — скрипты для SolidWorks 2017

Макросы для автоматической генерации 3D-моделей с деревом построения по 2D-чертежам.

## Как это устроено

```
скан / картинка чертежа  ──►  текстовое описание (spec)  ──►  VBA-макрос  ──►  .SLDPRT / .SLDASM с деревом построения
```

VBA не умеет распознавать изображения, поэтому шаг «картинка → описание» делается отдельно
(сейчас — вручную или с помощью Claude по присланному изображению), а макрос строит модели по описанию.

## Макросы

| Макрос | Что делает |
|---|---|
| `macros/BuildFromSpec.bas` | Строит детали (тела вращения + круговые массивы отверстий) и, если задано, сборку из них |

Дерево каждой детали:

```
Спереди ─► Эскиз «Profile» (контур + осевая) ─► «Body» (вращение 360°)
Plane_X… (смещение от «Справа») ─► «HolesN_Sketch» ─► «HolesN» (вырез)
«HolesN_Sketch» ─► «ThreadN_M4» (вырез под резьбу) + косметическая резьба на каждом отверстии
```

В сборке каждая деталь привязана тремя сопряжениями «Совпадение» своих плоскостей к плоскостям сборки.

## Установка и запуск

1. SolidWorks → **Инструменты → Макрос → Новый**, сохранить, например, `BuildFromSpec.swp`.
2. В редакторе VBA: **File → Import File…** → `macros/BuildFromSpec.bas`.
   Удалить пустой модуль, созданный по умолчанию.
3. **Tools → References**: должны быть отмечены *SldWorks 2017 Type Library* и
   *SOLIDWORKS 2017 Constant type library*.
4. В **Параметры → Шаблоны по умолчанию** должны быть заданы шаблоны детали и сборки.
5. **Инструменты → Макрос → Выполнить** и выбрать файл описания (`.txt`) в окне открытия файла.

Детали и сборка сохраняются в папку файла описания. Перед повторным запуском закройте
открытые документы с теми же именами, иначе сохранение не пройдёт.

## Формат описания

```
# комментарий (также ';', можно в конце строки)
ASSEMBLY <имя сборки>          необязательно; без неё строятся только детали

PART <имя детали>
P <x> <y>                      точка замкнутого профиля: X вдоль оси, Y — радиус, мм
...
HOLES <x> <dir> <n> <pcd> <d> <depth> <angle>
THREAD <x> <dir> <n> <pcd> <size> <depth> <angle> [<drillDepth>]
END
```

`HOLES` — круговой массив отверстий:

| Поле | Смысл |
|---|---|
| `x` | положение торца по оси, мм (плоскость эскиза) |
| `dir` | `1` — сверлить в сторону +X, `-1` — в сторону −X |
| `n` | количество отверстий |
| `pcd` | диаметр окружности центров, мм |
| `d` | диаметр отверстия, мм (резьбу задавать диаметром под резьбу: M3 → 2.5, M4 → 3.3, M5 → 4.2) |
| `depth` | глубина, мм; `0` — насквозь |
| `angle` | угол первого отверстия, градусы: 0 — по оси +Z, 90 — по +Y (вверх) |

`THREAD` — круговой массив резьбовых отверстий: вырез сверлом под резьбу + косметическая резьба
на каждом отверстии (на чертеже даёт обозначение резьбы). Поля те же, что у `HOLES`, но вместо
диаметра — размер резьбы (`M1.6`…`M20`, сверло подставляется само), `depth` — глубина резьбы,
`drillDepth` — глубина сверления (по умолчанию глубина резьбы + 0.5·d).
«Мастер отверстий» не используется: в SW 2017 через API он строил неверную геометрию.

- Последняя точка профиля соединяется с первой автоматически. Радиусы `Y ≥ 0`, контур без самопересечений.
- Фаски задаются точками, расточки — частью того же контура.
- Десятичный разделитель — точка или запятая. Имена — латиницей.

## Примеры

| Файл | Что получается |
|---|---|
| `examples/shaft.txt` | одна деталь — ступенчатый вал |
| `examples/DMRD-KB25.txt` | сборка DMRD-KB25: вал Ø38 (отдельная деталь) + корпус; чертёж — `examples/DMRD-KB25.png` |
| `examples/DMRD-KB32.txt` | сборка DMRD-KB32: вал Ø45 + корпус + выходной вал Ø112; чертёж — `examples/DMRD-KB32.png` |
